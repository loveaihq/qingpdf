# 第 3 层任务单 3d-2：阅读器的常用功能

3d-1 已完成：窗口、打开、滚动缩放、渲染调度、总内存上限。3d-2 加上日常阅读要用的功能。规则不变：界面全部自己写，`unsafe` 只在 `win32.rs`，不加依赖；新的引擎功能走 `qingpdf_core::view` 的消息式接口（以后鸿蒙版也用），并更新 `docs/view-api.md`。

## 交付

1. **菜单栏**：文件（打开、最近打开、打印、退出）、视图（缩放、旋转、显示书签）、转到（页码）、帮助（关于：版本号，第三方许可证见 `THIRD-PARTY-NOTICES.md`）。
2. **书签目录**：侧栏用系统的树控件，内容来自 `/Outlines`（标题按 PDFDocEncoding / UTF-16 解码，目标用已有的 `dests.rs` 解析，含命名目标和 GoTo 动作）。点了就跳到那页那个位置。条目数和深度设上限，循环引用能检测出来。没有书签的文件不显示侧栏。
3. **搜索**：Ctrl+F 打开搜索框，回车/F3 下一个，Shift+F3 上一个。
   - 用第 2 层的文字和位置。西文不分大小写；中文全角半角当作一样（用已有的规范化表）；跨行的词也能搜到（同一页里把行连起来，中文行尾不加空格）。
   - 在引擎线程上一页一页地搜，可以取消；先出第一个结果，后面的陆续出。命中的地方高亮。
4. **选字和复制**：用鼠标拖选，按阅读顺序选中字形；Ctrl+C 把文字（Unicode）放进剪贴板。
5. **链接**：
   - 页内链接（`/Dest`、GoTo）点了就跳；
   - 外部网址先弹框显示完整网址，确认后才用系统浏览器打开，只允许 http、https、mailto；
   - 鼠标移到链接上变手形。
6. **最近打开的文件**：最多 10 个，记住每个文件上次看到的页和缩放。存在 `%APPDATA%\qingpdf\` 下的一个 UTF-8 文本文件里，不联网；菜单里能清空。
7. **打印**：Ctrl+P 用系统打印对话框（页码范围、份数）。
   - 按打印机分辨率渲染，最高 300 dpi；按条带画，内存在 200 MB 总预算内；
   - 在引擎线程上做，界面不卡，可以取消，显示进度。
8. **权限**：和第 1.5 层、`qingpdf text` 命令的做法保持一致。没有所有者密码时，文件禁止复制就不能复制，禁止打印就不能打印，状态栏说明原因。实现前先看 `qingpdf text` 现在怎么处理，两边一样。
9. **限制**：书签条目、搜索结果、选中范围、链接个数都设上限；搜索和取文字的工作计入每页工作计量器。坏文件不崩、不卡。

## 验收

1. `cargo test --release` 全部通过，`cargo clippy` 无警告。逻辑（书签树、搜索匹配、选区、最近文件读写）和 Windows 调用分开，能单独测。
2. **搜索速度**（接电源，468 页的书）：第一个结果 ≤ 100 毫秒出现，搜完全书 ≤ 1 秒；中文公文里能搜到全角和半角写法的词。
3. **复制**：从中文公文复制一段，和 `qingpdf text` 输出的同一段一致。
4. **打印**：打印到系统自带的"Microsoft Print to PDF"，把输出文件名直接传给打印（`DOCINFO` 的输出路径），不弹保存框；再把打出来的 PDF 和原页面渲染对照，内容一致。打印过程内存 ≤ 200 MB。
5. `qingpdf-view.exe` 增加 ≤ 0.3 MB（总共仍 ≤ 3.3 MB）；`--bench` 翻页数字不变差。
6. 一次简短审查通过。

## 不做

缩略图、批注和表单的编辑（第 4 层）、深色模式、多标签页、全文索引、鸿蒙版本身。
