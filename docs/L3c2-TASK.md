# 第 3 层任务单 3c2：JBIG2、JPX 图片和批注

3c 之后还画成灰块的两种图片格式，加上批注的外观。全部自己写（用户定：别人的库没法控制大小）。分三小步，每步一个实现、一次简短审查：

| 小步 | 内容 | `qingpdf.exe` 增加 |
|---|---|---|
| **3c2-1** | JBIG2 解码 | ≤ 0.15 MB |
| **3c2-2** | JPX（JPEG 2000）解码 | ≤ 0.25 MB |
| **3c2-3** | 批注外观 | ≤ 0.05 MB |

三步共用：解码器放在 `render/` 下各自的模块里，接到 `image.rs` 现有的灰块位置；所有工作计入 3c 的每页工作计量器（`render/work.rs`），按真实开销加权；坏数据只影响那张图（灰块加警告），不崩、不卡；回归测试在代码里生成。

## 3c2-1 JBIG2

规范：ISO 32000-1 7.4.7（`JBIG2Decode`、`/JBIG2Globals`，嵌入格式没有文件头），ITU-T T.88。

- 段类型：符号字典、文字区域（直接和中间）、图案字典、半色调区域、通用区域、通用细化区域、页面信息、条带结束、页结束、表（自定义 Huffman）；扩展段跳过。
- 算术解码器（MQ 解码器，写成独立模块，3c2-2 的 JPX 也要用）；通用区域的模板 0–3、`TPGDON`、自适应像素；MMR 方式复用 3a 的 CCITT G4 解码器。
- 标准 Huffman 表 B.1–B.15 和自定义表；符号字典的导出和引用、聚合符号、细化。
- 限制：页面、区域、符号个数、符号总像素、Huffman 表大小。
- 验收：语料库里的 JBIG2 页和 PDFium 对照，差值和普通扫描页相当；300 dpi 扫描页 150 dpi 输出 ≤ 150 毫秒。

## 3c2-2 JPX

规范：ISO 32000-1 7.4.9（`JPXDecode`、`/SMaskInData`、颜色空间优先级），ISO/IEC 15444-1。

- JP2 盒子（`ihdr`、`colr`、`pclr`、`cmap`、`res` 可跳过）和裸码流两种。
- 码流：SIZ、COD/COC、QCD/QCC、POC、SOT/SOD、PPM/PPT，RGN 可只解析不用；多个瓦片、瓦片部分、分量下采样、1–16 位、有符号。
- 第二层：标签树、包头、五种渐进顺序、区（precinct）。第一层：EBCOT 编码块（三种通道、旁路模式、重置、TERMALL、分段符号、竖直因果），复用 3c2-1 的 MQ 解码器。
- 反量化（无量化、标量导出、标量明示）、5/3 可逆和 9/7 不可逆小波逆变换、RCT/ICT 分量变换；sRGB、灰度、sYCC，ICC 按通道数近似；调色板。
- **按输出分辨率少解几级**：画到页面上用不到全分辨率时，只解需要的分辨率级（这是速度的关键）。
- 限制：瓦片数、编码块数、通道数、图像尺寸、中间缓冲内存。
- 验收：语料库里的 JPX 页和 PDFium 对照；A4 整页 JPX 照片 150 dpi 输出 ≤ 150 毫秒；内存 ≤ 200 MB。

## 3c2-3 批注外观

规范：ISO 32000-1 12.5（特别是 12.5.5 外观流，按 `/Rect`、`/BBox`、`/Matrix` 放置的算法）、12.5.3 标志。

- 画 `/AP /N`，有 `/AS` 时选对应状态；`Hidden`、`NoView` 不画；批注的 `/OC`。`Popup` 不画（那是界面的事）。
- 表单控件没有外观流时先跳过并警告（按 `NeedAppearances` 生成外观放到编辑那一层）。
- `render` 默认画批注，加 `--no-annots` 选项。`render_compare.py --engine-compare` 让 PDFium 也画批注（`FPDF_ANNOT`）。
- 验收：有批注的语料页和 PDFium 对照；没有批注的页结果不变。

## 不做

ICC 颜色管理、按 `NeedAppearances` 生成外观、界面（3d）。
