# 任务单：阅读器里的合并、图片转 PDF（2026-11-03）

分工（用户定）：Dell 上把这些补进 `qingpdf-view`，提交推送后 Mac 那边才开始把 Windows 部分隔开，两边不同时改同一批文件。

「去掉密码」不用做：「文件 → 密码和权限」已经能把密码去掉（`app/protect.rs`）。

引擎已有，命令行早就在用，阅读器只做界面，不改引擎：

- 合并：`qingpdf_core::ops::merge(&[Input { name, doc, password }])`
- 图片转 PDF：`qingpdf_core::ops::images_to_pdf_with(count, load, PageMode::{A4, Fit})`，一次只读一张图

## 6a 合并

1. 菜单「文件 → 合并 PDF…」。
2. 先弹 Windows 的打开框，**允许多选**，只列 .pdf；当前打开的文件默认排第一。
3. 再弹一个小框列出这些文件：可以上移、下移、删除、再添加。顺序就是合并的顺序。
4. 有密码的文件打开时问密码（用现有的问密码框）；输错了能重输，取消就从列表里去掉这个文件。
5. 选保存位置：默认放在第一个文件旁边，文件名加「-合并」。
6. 在后台做，状态栏显示进度，按 Esc 停止；做完后问要不要打开。引擎给的警告（比如丢了哪些书签）显示出来。

## 6b 图片转 PDF

1. 菜单「文件 → 图片转 PDF…」，欢迎页上也放一个入口。
2. 打开框多选，只列 .jpg、.jpeg、.png，按文件名的自然顺序排（2 排在 10 前面）。
3. 用同一种列表框调顺序；框里加一项页面大小：「A4」（默认）或「和图片一样大」。
4. 保存、进度、Esc、问打开：和 6a 一样。
5. 也支持把图片直接拖进窗口：拖进来的全是图片时，直接走这个流程，并且已经按拖进来的文件填好列表。

## 共同要求

- 6a 和 6b 共用一个「文件列表」框（上移、下移、删除、添加），写在 `app/` 下的新文件里；`unsafe` 只在 `win32.rs`；不加依赖。
- 中英文文字都要有（`i18n.rs`）；读屏软件模式下也能用。
- **体积**：阅读器现在 3,953,664 字节，上限 4.0 MB，只剩约 45 KB。图片转 PDF 要把 PNG 解码拉进阅读器，可能放不下。先量一下：放不下就先瘦身，还是放不下就停下来，用文字问用户。
- 测试：列表的排序和增删、自然顺序、默认文件名、问密码时取消；对合并和图片转 PDF 的结果各做一次往返检查（用 qpdf `--check`，并核对页数）。
- 完成标准：`cargo test --workspace --release` 全过，`clippy` 没有警告，体积在上限内；USER-GUIDE.md 和 使用说明.md 补上这两个功能。

## 顺序

先 6a，再 6b，每步一次实现、一次简短审查。两步都做完后提交推送，告诉用户 Mac 那边可以开始了。
