# 第 3 层任务单 3c：透明、渐变、图案

原来的 3c 太大，再拆成两步：

| 步 | 内容 |
|---|---|
| **3c（本单）** | 透明组、软蒙版、混合模式、渐变（shading）、图案、可选内容（图层）显示、CMYK 颜色改进 |
| 3c2 | JBIG2、JPX（JPEG 2000）图片解码，批注外观 |

## 规范

ISO 32000-1：8.7.3（图案：平铺和渐变图案）、8.7.4.5（shading 类型 1–7）、8.11（可选内容）、第 11 章（透明：11.3 混合模式、11.4 透明组、11.5–11.6 软蒙版和 `ExtGState` 里的 `SMask`/`BM`/`CA`/`ca`/`AIS`、knockout 和 isolated 组）。代码注明章节号。

## 交付

1. **透明**：透明组（isolated / non-isolated、knockout）、组的颜色空间、软蒙版（`/Luminosity`、`/Alpha`，含 `/BC` 背景色和 `/TR` 传递函数）、全部 16 种混合模式（tiny-skia 支持的直接用，不支持的自己写）、`/AIS`。3a 里已经做的图片 `/SMask` 和 `ca`/`CA` 并入这套。
2. **渐变**：shading 类型 1（函数）、2（轴向）、3（径向），含 `/Extend`、`/Domain`、`/Background`、`/BBox`；类型 4–7（三角网格、格子网格、Coons 和张量曲面）自己栅格化（细分成小三角形或小块，精度按输出分辨率定）。`sh` 操作符和渐变图案都要。
3. **图案**：平铺图案（彩色和无色，`/XStep`/`/YStep`/`/Matrix`，图块先画到小图上再平铺；图块太大或太小时按比例取样，不要逐块重画内容流）。
4. **可选内容**：按默认配置（`/OCProperties /D`）隐藏关掉的图层，含 `/OCMD` 和 `/VE` 表达式、`BDC /OC` 标记内容、XObject 和批注的 `/OC`。
5. **CMYK 转 RGB 改进**：3a 用的多项式在纯黄、纯品红上偏差大，换成更准的近似（比如按 PDFium/pdf.js 的做法或小查表插值），和 PDFium 对照色块。
6. **限制**：组嵌套深度、同时存在的图层（离屏缓冲）总字节数、网格三角形数、细分深度、平铺图块数和图块像素数，都设上限，并计入每页预算。超了跳过那个对象并警告，不崩、不卡。回归测试在代码里生成。

## 验收

1. `cargo test --release` 全部通过，`cargo clippy` 无警告。
2. **和 PDFium 对照**：`render_compare.py --engine-compare` 全量跑。3a 报告里标"3c 功能"的页（除 JBIG2/JPX 灰块外）差值降到和普通页相当；全部页面平均值不比 3b2 的 2.53 差。另找或生成一组透明和渐变测试页（各种混合模式、软蒙版、shading 1–7、平铺图案）一起对照。
3. **快和小**（接电源时量）：普通文字页仍 ≤ 50 毫秒；透明和渐变较多的页 ≤ 150 毫秒；内存 ≤ 200 MB；`qingpdf.exe` 增加 ≤ 0.4 MB。
4. 一次简短审查通过。

## 不做

JBIG2、JPX、批注外观（3c2）；界面（3d）；ICC 颜色管理（仍按通道数近似）。
