# qingpdf 使用说明

## 1. 是什么

qingpdf 是一个小、快、离线的 PDF 工具。它不用安装，不联网，也不收集任何数据。

它包括两个程序：

- **qingpdf-view.exe**：阅读器。用来看 PDF，也可以批注、填表、改字、导出 Word 和 Excel。
- **qingpdf.exe**：命令行工具。用几条命令合并、拆分、加水印等，适合一次处理很多文件。

两个程序都只有几 MB。目前只支持 Windows。

## 2. 下载和打开

1. 把 zip 压缩包解压到一个文件夹（右键 → 全部提取）。
2. 双击 **qingpdf-view.exe**。
3. 按 Ctrl+O 选择 PDF 文件，或者直接把 PDF 拖进窗口。

第一次运行时，Windows 可能提示“已保护你的电脑”。这是因为程序没有付费签名，不是程序有问题。点“更多信息”，再点“仍要运行”即可。

如果菜单是英文的，点菜单 View（视图）→ Language（语言），选“中文”，马上生效。窗口的大小和位置、语言、工具栏、侧栏的标签和宽度，下次打开时会记住。

## 3. 阅读器怎么用

菜单在窗口顶部，菜单下面是工具栏（“视图 → 工具栏”可以隐藏它）。按 Esc 可以停止打印、导出和文字识别。

### 文件

| 功能 | 快捷键 | 做什么 |
|---|---|---|
| 打开 | Ctrl+O | 选一个 PDF 文件打开 |
| 最近打开 | — | 列出最近打开过的文件；“清空列表”删掉这些记录 |
| 保存 | Ctrl+S | 把你做的改动保存到这个文件 |
| 另存为 | Ctrl+Shift+S | 存成另一个文件，并整个重写一遍，改掉的旧字不会留在新文件里 |
| 导出为 Word | — | 转成可以编辑的 Word 文件（.docx） |
| 导出为 Excel | — | 把表格转成 Excel 文件（.xlsx），一个表格一个工作表 |
| 打印 | Ctrl+P | 打印当前文件 |
| 退出 | — | 关闭阅读器 |

**打开加密文件：** 文件需要密码时，窗口会要你输入；密码不对会再问一次。只限制打印、复制的文件不用密码就能打开。如果作者不允许复制、打印、批注、填表或修改，相应的功能会提示“需要所有者密码”。所有者密码是作者设的管理密码，一般人没有，所以这些功能用不了。

### 编辑

| 功能 | 快捷键 | 做什么 |
|---|---|---|
| 撤销 | Ctrl+Z | 撤销上一步改动，保存以后也能撤销 |
| 重做 | Ctrl+Y | 把撤销的那一步再做一遍 |
| 复制 | Ctrl+C | 复制选中的文字 |
| 查找 | Ctrl+F | 输入要找的字，回车找下一处；全角和半角、大小写都当作一样 |
| 查找下一个 | F3 | 找下一处 |
| 查找上一个 | Shift+F3 | 找上一处 |

工具栏上也有搜索框，输入后按回车就能找。

### 视图

| 功能 | 快捷键 | 做什么 |
|---|---|---|
| 放大 | Ctrl++ | 放大页面 |
| 缩小 | Ctrl+- | 缩小页面 |
| 适合宽度 | Ctrl+1 | 页面宽度正好填满窗口 |
| 适合整页 | Ctrl+2 | 整页正好放进窗口 |
| 实际大小 | Ctrl+0 | 按实际大小显示 |
| 顺时针旋转 | Ctrl+R | 把页面转 90 度，只改变这次看的方向，不改文件 |
| 显示侧栏 | F4 | 显示或隐藏页面旁边的侧栏。侧栏上方有两个标签：“书签”（目录）和“缩略图”（每页一张小图，大小固定，拖宽侧栏也不会变大；当前页有蓝框；点一下跳到那页，点过之后 ↑ ↓ PgUp PgDn Home End 一页页走，右边的细条可以拖；点页面或工具栏键盘还给页面）。没有书签的文件，F4 直接打开缩略图。拖侧栏的边可以改宽窄；下次打开记得上次用的标签 |
| 工具栏 | — | 显示或隐藏工具栏 |
| 语言 | — | 选“跟随系统”“中文”或“English”，马上生效 |

### 批注

批注是盖在页面上的标记，不会改动原来的字。

| 功能 | 快捷键 | 做什么 |
|---|---|---|
| 选择 | Esc | 回到普通状态，可以选字 |
| 高亮 | — | 拖过要标记的文字，给它涂上颜色 |
| 下划线 | — | 给拖过的文字加下划线 |
| 删除线 | — | 给拖过的文字加删除线 |
| 波浪线 | — | 给拖过的文字加波浪线 |
| 手写 | — | 按住鼠标拖动来画 |
| 便签 | — | 点一下放便签的位置，然后输入便签文字 |
| 文字框 | — | 拖出一个框，在里面输入文字；点框外或按 Ctrl+Enter 完成，Esc 结束 |
| 签名图片 | — | 选一张 PNG 或 JPEG 图片（比如签名的图片），拖动移动，拖角缩放，按 Enter 放好，Esc 取消 |
| 颜色 | — | 选批注的颜色：黄、绿、蓝、粉、红、黑 |
| 线宽 | — | 选细、中、粗、特粗 |
| 字号 | — | 文字框的字号：小（10 磅）、中（12 磅）、大（16 磅）、特大（24 磅） |
| 作者名 | — | 设置你加的批注上署的名字 |
| 删除批注 | Del | 选中批注后删除（Ctrl+Z 可以撤销） |

### 插入

这些功能会把内容写进页面本身，打印和别的软件也能看到。

| 功能 | 做什么 |
|---|---|
| 加文字 | 在页面上加一段文字（支持中文） |
| 加图片 | 选一张 PNG 或 JPEG 图片，放到页面上 |
| 加水印 | 输入水印文字，可以设透明度和角度；可以平铺满页，可以垫在页面内容下面，也可以只加在当前页 |
| 改页面上的文字 | 点一行文字，输入新的内容，按回车确认（Esc 取消）。原来的字会从页面里去掉 |

**改字注意：** 一次只能改一行，跨行的段落要分开改。新字比原来宽时，会提示可能压到后面的字。改完后旧字仍留在文件的旧版本里，要彻底去掉，请用“另存为”。

### 工具

| 功能 | 做什么 |
|---|---|
| 识别所有扫描页的文字 | 扫描件是一张张图片，没有文字。用它让 Windows 认出图上的字，之后就能搜索和复制 |
| 识别当前页的文字 | 只识别这一页 |

识别在本机完成，不联网，也不下载；已有文字的页会跳过。识别出的文字可以用“撤销”去掉。

需要 Windows 的中文语言包：打开“设置 → 时间和语言 → 语言和区域”，添加中文。阅读器不会改动系统设置。

### 转到

| 功能 | 快捷键 | 做什么 |
|---|---|---|
| 上一页 | Ctrl+PgUp | 翻到上一页 |
| 下一页 | Ctrl+PgDn | 翻到下一页 |
| 页码 | Ctrl+G | 输入页码，跳到那一页 |

工具栏上的页码框也可以直接输入页码，回车跳转。

### 帮助

| 功能 | 做什么 |
|---|---|
| 关于 qingpdf | 显示版本号和简介 |

### 页面上直接操作

- 拖动鼠标可以选中文字。双击选一个词（中文是到标点为止的一整段），三击选一行。
- 在页面上点右键，可以复制、高亮所选文字、在此添加便签、选择本页全部文字。
- **填表**：页面上的表单框，直接点进去填写。填错了按 Ctrl+Z 撤销。

## 4. 命令行工具

**怎么打开命令行窗口：** 在放着 qingpdf.exe 的文件夹里，点击窗口上方的地址栏，输入 `cmd`，按回车。弹出的黑色窗口就是命令行窗口。在里面输入下面的命令，按回车执行。

注意：

- 文件名中间有空格时，要用英文双引号括起来，例如 `"合同 终稿.pdf"`。
- 已经存在的输出文件不会被覆盖。要覆盖，就在命令最后加上 `--force`。
- 页码写法：`1-3,5` 是第 1、2、3、5 页；`8-` 是第 8 页到最后一页。
- 加密的文件，加上 `--password 密码`。

**查看信息**：显示页数、页面大小、文件信息，以及是否加密。

```
qingpdf info 合同.pdf
```

**合并**：按顺序把几个 PDF 接在一起。

```
qingpdf merge 合同.pdf 附件.pdf -o 合并.pdf
```

**拆分**：`--pages` 取出指定的页；`--every` 每 N 页切成一个文件，输出名里要有 `%d`，它会变成 1、2、3……

```
qingpdf split 合同.pdf --pages 1-3,5 -o 前三页和第五页.pdf
qingpdf split 合同.pdf --every 10 -o 第%d份.pdf
```

**删页**：删掉指定的页。

```
qingpdf delete 合同.pdf --pages 2,4-6 -o 删页后.pdf
```

**旋转**：把指定的页顺时针转 90 度；`--angle -90` 是逆时针。不写 `--pages` 就是全部页。

```
qingpdf rotate 扫描件.pdf --pages 1-3 --angle 90 -o 转正.pdf
```

**去掉加密**：写出一个没有密码的副本。只有知道所有者密码，或者文件本来允许一切操作时才能用。

```
qingpdf decrypt 加密合同.pdf -o 无密码合同.pdf --password 密码
```

**提取文字**：按阅读顺序输出文字；不写 `-o` 就直接显示在窗口里。扫描件没有文字，要先在阅读器里识别。

```
qingpdf text 合同.pdf -o 合同.txt
```

**画成图片**：每页存成一张 PNG。`--dpi` 越大越清楚，默认是 150。

```
qingpdf render 合同.pdf --pages 1-3 --dpi 150 -o 第%d页.png
```

**图片转 PDF**：每张图片一页，按写的顺序排。默认放在 A4 纸上；加 `--page fit` 则页面大小和图片一样。

```
qingpdf img2pdf 第一张.jpg 第二张.png -o 图片合集.pdf
```

**加水印**：加文字水印。`--tile` 铺满整页，`--angle` 设角度，`--opacity` 设透明度（0 到 1），`--under` 垫在页面内容下面，`--pages` 指定页。也可以用 `--image 水印.png` 加图片水印。

```
qingpdf watermark 合同.pdf --text "机密" --opacity 0.3 --angle 45 --tile -o 加水印.pdf
```

**盖图片**：把签名或图标等图片放到指定页。`--at` 是图片左下角的位置，`--width` 是宽度，单位都是点（1 英寸 = 72 点）。

```
qingpdf stamp 合同.pdf --image 签名.png --page 3 --at 72,100 --width 120 -o 盖章后.pdf
```

**加文字**：在指定页的指定位置加一段文字。`--at` 是第一行文字的左下角位置，`--size` 是字号（点）；文字里写 `\n` 可以换行。

```
qingpdf addtext 合同.pdf --page 1 --at 72,720 --size 12 --text "你好" -o 加字后.pdf
```

**替换文字**：把页面上的“旧词”改成“新词”，只在一行之内找，不跨行。旧字仍在文件前面的内容里；要彻底去掉，再用 `qingpdf split 改字后.pdf --pages 1- -o 干净版.pdf` 重写一遍。

```
qingpdf replace 合同.pdf --find "旧词" --replace "新词" --pages 1-3 -o 改字后.pdf
```

**转 Word**：把页面转成可以编辑的 Word 文件。

```
qingpdf docx 报告.pdf --pages 1-10 -o 报告.docx
```

**转 Excel**：把页面里的表格转成 Excel 文件，一个表格一个工作表。

```
qingpdf xlsx 对账单.pdf --pages 1-10 -o 对账单.xlsx
```

## 5. 已知限制

1. **只有 Windows 版。** 阅读器和命令行工具都只能在 Windows 上运行。
2. **只认横排文字。** 文字识别只认横排。竖排的老书扫描件识别出来会是跨栏的横行，顺序会乱。
3. **没有框线的表格可能认不准。** 转 Excel 和 Word 时，没有框线的表靠文字对齐找出来。两列的“名称 | 说明”这类表、列间距很紧的表认不出来；有的图也可能被当成表。
4. **改字有限制。** 一次只改一行，跨行的段落不能一起改；有些重复使用的表单里的字也改不了。改完的旧字仍在文件的旧版本里，要彻底去掉，请用“另存为”。
5. **有签名的文件不能改内容。** 加水印、加图片、加文字、改字都会被拒绝。“签名图片”只是把图片放上去，不是数字签名；本程序不能签名，也不能验证签名。
6. **转成的 Word 和 Excel 不是原样复制。** Word 文件是可以编辑的版面，不会和原页一模一样；图表和绘制的图形不会转过去。
