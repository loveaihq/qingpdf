# qingpdf 使用说明

## 1. 是什么

qingpdf 是一个小、快、离线的 PDF 工具。它不用安装，不联网，也不收集任何数据。

它包括两个程序：

- **qingpdf-view.exe**：阅读器。用来看 PDF，也可以批注、填表、改字、导出 Word 和 Excel。
- **qingpdf.exe**：命令行工具。用几条命令合并、拆分、加水印等，适合一次处理很多文件。

两个程序都只有几 MB。目前只支持 Windows。

## 2. 下载和打开

1. 把 zip 压缩包解压到一个文件夹（右键 → 全部提取）。
2. 双击 **qingpdf-view.exe**。
3. 按 Ctrl+O 选择 PDF 文件，或者直接把 PDF 拖进窗口。

第一次运行时，Windows 可能提示“已保护你的电脑”。这是因为程序没有付费签名，不是程序有问题。点“更多信息”，再点“仍要运行”即可。

如果菜单是英文的，点菜单 View（视图）→ Language（语言），选“中文”，马上生效。窗口的大小和位置、语言、工具栏、侧栏的标签和宽度，下次打开时会记住。

## 3. 阅读器怎么用

菜单在窗口顶部，菜单下面是工具栏（“视图 → 工具栏”可以隐藏它）。按 Esc 可以停止打印、导出、压缩和文字识别。

### 文件

| 功能 | 快捷键 | 做什么 |
|---|---|---|
| 打开 | Ctrl+O | 选一个 PDF 文件打开 |
| 最近打开 | — | 列出最近打开过的文件；“清空列表”删掉这些记录 |
| 保存 | Ctrl+S | 把你做的改动保存到这个文件 |
| 另存为 | Ctrl+Shift+S | 存成另一个文件，并整个重写一遍，改掉的旧字不会留在新文件里 |
| 导出为 Word | — | 转成可以编辑的 Word 文件（.docx） |
| 导出为 Excel | — | 把表格转成 Excel 文件（.xlsx），一个表格一个工作表 |
| 密码和权限 | — | 看这个文件现在怎么加密、限制了什么；设打开密码和权限密码，选 AES-256 或 AES-128，关掉打印、复制等权限，或者去掉密码（见下面“设密码和权限”） |
| 压缩 | — | 把文件变小，存成一个新文件（见下面“压缩文件”） |
| 打印 | Ctrl+P | 打印当前文件 |
| 退出 | — | 关闭阅读器 |

**打开加密文件：** 文件需要密码时，窗口会要你输入；密码不对会再问一次。只限制打印、复制的文件不用密码就能打开。如果作者不允许复制、打印、批注、填表或修改，相应的功能会提示“需要所有者密码”。所有者密码是作者设的管理密码，一般人没有，所以这些功能用不了。

**设密码和权限：** 文件 → 密码和权限…，窗口最上面一栏写着这个文件现在的保护（加密方式、打开要不要密码、哪些权限被关了）。下面可以设：

- **打开密码**：要打开文件就得输入的密码，各输两遍；留空是不需要密码。
- **权限密码**（所有者密码）：能解除下面所有限制的密码，各输两遍；留空是和打开密码一样。**只要关了任何一项权限，就必须设权限密码**，否则别人一个选项就能把限制打开，等于没限制。
- **加密方式**：AES-256（推荐，新的 PDF 阅读器都认）或 AES-128（给很老的软件用）。AES-128 的密码只能用拉丁字母，最多 32 个；有汉字的密码请用 AES-256（最多 127 个字节，一个汉字占 3 个）。
- **权限**：打印（允许高质量 / 只允许低质量 / 不允许）、复制文字和图片、修改内容、加批注、填写表单、插入删除旋转页面、为读屏软件提取内容。
- **去掉密码**：点窗口左下角的按钮，不带任何密码保存一份。

点“保存…”后选存到哪里：默认是这个文件本身（Windows 会问是不是覆盖），也可以另存一个新名字。保存是把整个文件重写一遍，**还没保存的改动一起存进去**，写完后自动重新打开（用权限密码打开，所以你接着是有全部权利的；以后别人打开时才受限制）。文件已经加密、又被作者限制了权限的，要先用所有者密码打开才能改；有数字签名的文件改不了（重写会弄坏签名）。**密码忘了没办法找回**，请自己记好。

注意：带遮挡的密码框里，Windows 常常不让中文输入法工作，要输中文密码可以从别处复制了粘贴进来。

**压缩文件：** 文件 → 压缩…，选一档，点“压缩…”，再选存到哪里（默认是这个文件旁边，名字后面加“-压缩”）。压缩在后台做，状态栏显示进度，**按 Esc 可以停**；做完会告诉你前后各多大，问要不要打开新文件。原文件不会改动。

- **每一档都会做的（不损失任何东西）：** 没人用的内容不写进新文件；重复的内容只存一份（每页都带一份的字体、图片、颜色配置文件、资源）；对象打包成对象流、目录表改成压缩的交叉引用流（PDF 1.5；文件自己说是 PDF/A-1 的不打包，写成传统的目录表，因为那个标准不许用对象流，压缩时会说一声）；数据流用最强的 Flate 重新压一遍，没压过的压上；去掉页面缩略图、做这个文件的程序留下的私有数据、页面和图片上的元数据（整份文件的元数据和文档信息留着）。
- **图片（三档的区别）：** 图片画得比这一档的“每英寸点数”还精细时，缩到那个大小再存成 JPEG，只在结果更小时才换。**高质量**：200 dpi，JPEG 质量 85；**平衡**：150 dpi，质量 75（默认）；**最小**：100 dpi，质量 60。图片缩到多大，看它在哪一页画得最大（页面、表单、批注的外观都查）。勾上“只做无损压缩”就只做上面那一条，图片一点不动。
- **不动的图片：** 黑白图和蒙版（只重新压缩）；带 `/Decode` 或颜色键蒙版的、CMYK 的、索引颜色的、16 位的；平铺图案、Type 3 字形、软蒙版组里画的图。带软蒙版的图，蒙版跟着缩到同样大小。
- **永远不会变大：** 压完不比原来小，就不生成新文件，并告诉你。
- **加密文件：** 新文件保持原来的加密（同样的方法、同样的密码）。作者不允许修改内容的文件，要缩小图片得用所有者密码打开；只做无损压缩（勾上“只做无损压缩”）不需要，和转页、删页一样；有数字签名的文件不能压缩（重写会弄坏签名）。
- **没保存的改动：** 压缩前会问要不要先保存；不保存就不压缩。超过 30 MB 的文件阅读器里不压缩（占内存太多），窗口很大（比如 4K 屏）时约 16 MB 以上的文件也不行，会告诉你；请用命令行。

### 插入

这些功能会把内容写进页面本身，打印和别的软件也能看到。

| 功能 | 做什么 |
|---|---|
| 加文字 | 在页面上加一段文字（支持中文） |
| 加图片 | 选一张 PNG 或 JPEG 图片，放到页面上 |
| 加水印 | 输入水印文字，可以设透明度和角度；可以平铺满页，可以垫在页面内容下面，也可以只加在当前页 |
| 页码和页眉页脚… | 一个窗口：页眉、页脚各有左、中、右三处，一共六处文字，每处点下拉箭头可以挑常用的写法（`{page}`、`第 {page} 页`、`第 {page} 页 共 {pages} 页`、`- {page} -`、`{page} / {pages}`、`Page {page} of {pages}`），也可以自己写；可以设字号、颜色、离页边的距离（毫米）、从第几页到第几页（不填是全部）、起始编号（例如从第 3 页起写 1）、单双页对称（双面打印时页码在外侧，公文的写法）、首页不加。右边的小图随着输入显示当前这一页的样子。窗口里的“删除已有的页码和页眉页脚”只删本程序加的那些。可以撤销，保存时和别的改动写成同一次追加 |
| 改页面上的文字 | 点一行文字，输入新的内容，按回车确认（Esc 取消）。原来的字会从页面里去掉 |

**页码和页眉页脚的字段：** 文字里写 `{page}` 是这一页的页码，`{pages}` 是最后一页的页码（整份文件从 1 起编，就是总页数），`{date}` 是今天的日期（例如 2026-10-15，阅读器用电脑上的日期），`{file}` 是文件名（不带文件夹）；别的字照原样写出来。

**页码注意：**

- 页码和页眉页脚是写进页面的，打印和别的软件也看得到；它们标成页面的页眉和页脚（不算正文），所以提取文字、查找、复制、导出 Word 和 Excel 都不含它们。
- 页码从范围里的第一页算起：范围是第 3 页到最后、起始编号写 1，第 3 页就是 1。选了“首页不加”，范围里的第一页不写，但仍算一页（下一页是 2）。
- “单双页对称”按页在文件里的位置：第 2、4、6…页是左页，这几页上左、右两处的文字互换，中间的不动。要页码在外侧，就把它写在右边。
- 再用一次会再加一套；要换成新的，先点“删除已有的页码和页眉页脚”。它只认本程序加的，别的软件加的页码删不掉，别的软件改写过文件之后也可能认不出来（认不出来就不动）。删除之后字体仍在文件里（几 KB）。
- 文字需要的字都得在系统字体里找得到，找不到会说哪个字没有。有签名的文件、作者不允许改内容的文件不能加（和加水印一样）。

**改字注意：** 一次只能改一行，跨行的段落要分开改。新字比原来宽时，会提示可能压到后面的字。改完后旧字仍留在文件的旧版本里，要彻底去掉，请用“另存为”。

### 管理页面（缩略图栏）

在“缩略图”标签里选页，再旋转、删除、调顺序、插入、提取。所有操作都可以用 Ctrl+Z / Ctrl+Y 撤销、重做（和批注、改字在同一条撤销记录里）。

| 做什么 | 怎么做 |
|---|---|
| 选页 | 点一张选一页；Ctrl+点 加选或去掉；Shift+点 选一段；在缩略图栏里按 Ctrl+A 全选。选中的页有蓝底 |
| 向左 / 向右旋转 | 右键 → 向左旋转、向右旋转，或 Ctrl+[ 、Ctrl+]（改的是页面自己的 /Rotate，保存后别的软件看到的也是转过的） |
| 删除 | 右键 → 删除，或在缩略图栏里按 Delete。不能删光所有页。删掉页上的表单字段一起去掉；书签和链接指向被删的页时点了没反应 |
| 调顺序 | 按住选中的页拖到新位置，橙色横线是放下的位置；拖到栏的上下边缘会自动滚动；Esc 取消 |
| 从文件插入页 | 右键 → 从文件插入页：之前 / 之后…，选一个 PDF，把它的全部页插进来（带批注、表单字段、链接；不带书签；字段重名会自动改名；对方文件里的数字签名不带过来，签名字段留着但是空的）。文件不能超过 16 MB，也不能超过没保存的改动剩下的内存，放不下时提示先保存文件或者换小一点的文件。要密码的文件会问密码；权限不全（有任何限制）又没给所有者密码的文件会被拒绝，和命令行合并的规矩一样 |
| 提取为新 PDF | 右键 → 提取为新 PDF…，把选中的页写成一个新文件（不碰正在看的文件；有加密的保持原来的加密）。文件作者不许复制时不能提取 |

保存（Ctrl+S）是增量保存：新的页面树、转过的页、插进来的页追加在原文件后面，原文件的字节原样留着，所以**删掉的页仍在保存后文件的旧版本部分里**；要真正去掉，用“另存为”（整个文件重写）。文件作者不许“拼装”页面（权限位 11）又没用所有者密码打开时，这些命令是灰的；有签名的文件不能改页。

### 页面上直接操作

- 拖动鼠标可以选中文字。双击选一个词（中文是到标点为止的一整段），三击选一行。
- 在页面上点右键，可以复制、高亮所选文字、在此添加便签、选择本页全部文字。
- **填表**：页面上的表单框，直接点进去填写。填错了按 Ctrl+Z 撤销。

## 4. 命令行工具

**怎么打开命令行窗口：** 在放着 qingpdf.exe 的文件夹里，点击窗口上方的地址栏，输入 `cmd`，按回车。弹出的黑色窗口就是命令行窗口。在里面输入下面的命令，按回车执行。

注意：

- 文件名中间有空格时，要用英文双引号括起来，例如 `"合同 终稿.pdf"`。
- 已经存在的输出文件不会被覆盖。要覆盖，就在命令最后加上 `--force`。
- 页码写法：`1-3,5` 是第 1、2、3、5 页；`8-` 是第 8 页到最后一页。
- 加密的文件，加上 `--password 密码`。

**查看信息**：显示页数、页面大小、文件信息，以及是否加密。

```
qingpdf info 合同.pdf
```

**合并**：按顺序把几个 PDF 接在一起。

```
qingpdf merge 合同.pdf 附件.pdf -o 合并.pdf
```

**拆分**：`--pages` 取出指定的页；`--every` 每 N 页切成一个文件，输出名里要有 `%d`，它会变成 1、2、3……

```
qingpdf split 合同.pdf --pages 1-3,5 -o 前三页和第五页.pdf
qingpdf split 合同.pdf --every 10 -o 第%d份.pdf
```

**删页**：删掉指定的页。

```
qingpdf delete 合同.pdf --pages 2,4-6 -o 删页后.pdf
```

**旋转**：把指定的页顺时针转 90 度；`--angle -90` 是逆时针。不写 `--pages` 就是全部页。

```
qingpdf rotate 扫描件.pdf --pages 1-3 --angle 90 -o 转正.pdf
```

**去掉加密**：写出一个没有密码的副本。只有知道所有者密码，或者文件本来允许一切操作时才能用；有签名的文件不行（整个文件重写会弄坏签名）。

```
qingpdf decrypt 加密合同.pdf -o 无密码合同.pdf --password 密码
```

**加密码、设权限**：写出一个加了密码、关了某些权限的副本，默认用 AES-256（`--aes128` 是 AES-128）。`--user-password` 是打开密码，`--owner-password` 是权限密码（只给打开密码时，权限密码和它一样）；密码也可以放在一个文本文件里用 `--password-file` 读（第一行是打开密码，第二行是权限密码，哪一行可以是空的），这样别人看不到你敲的命令里有什么；密码前后不能有空格，也不能有控制字符（在 cmd 里用 `echo 密码 > 文件` 写会在密码后多出一个空格，会被拒绝；请用记事本写，存成 UTF-8）。权限默认都开着，用这些选项关：`--print none|low|high`（不许打印 / 只许低质量 / 高质量），`--no-copy`（复制文字和图片）、`--no-modify`（修改内容）、`--no-annotate`（批注）、`--no-forms`（填表）、`--no-assemble`（插入、删除、旋转页面）、`--no-accessibility`（给读屏软件提取）；`--cleartext-metadata` 不加密文档的元数据（让搜索程序读得到）。关了任何一项权限必须给权限密码；一个密码也不给又不关任何权限，会拒绝（没有东西可保护）。输入文件已经加密的，用 `--password` 给它的密码，并且要有所有者的权利（和 `decrypt` 同一条规矩）；有签名的文件会被拒绝。输出是整个重写的新文件，不能和输入同名。密码不会出现在任何输出里。

```
qingpdf encrypt 合同.pdf -o 加密合同.pdf --user-password 打开用的密码 --owner-password 管理用的密码
qingpdf encrypt 报告.pdf -o 只读报告.pdf --owner-password 管理用的密码 --no-copy --no-modify --print low
qingpdf encrypt 合同.pdf -o 兼容旧软件.pdf --aes128 --password-file 密码.txt
```

要去掉密码，用上面的 `decrypt`；要换密码，对加密的文件再运行一次 `encrypt`（`--password` 给旧密码）。

**压缩**：写出一个更小的副本，并打印前后各多少字节。`--preset high|balanced|small` 选一档（默认 `balanced`：图片画得超过 150 dpi 就缩到 150 dpi，JPEG 质量 75；`high` 是 200 dpi、质量 85；`small` 是 100 dpi、质量 60），`--lossless` 只做不损失任何东西的那部分（图片不动）。每次都做：丢掉没人用的内容、合并重复的对象、打包成对象流和压缩的交叉引用流、数据流重新压到最强、去掉缩略图和私有数据。加密文件用 `--password` 给密码，新文件保持原来的加密；作者不允许修改内容的文件，缩小图片要给所有者密码，`--lossless` 不用；有签名的文件会被拒绝。**输出永远不会比输入大**：压完不比原来小，输出就是输入的一份拷贝，命令会明说。

```
qingpdf compress 扫描件.pdf -o 小扫描件.pdf
qingpdf compress 画册.pdf -o 画册小.pdf --preset small
qingpdf compress 合同.pdf -o 合同小.pdf --lossless
```

**提取文字**：按阅读顺序输出文字；不写 `-o` 就直接显示在窗口里。扫描件没有文字，要先在阅读器里识别。

```
qingpdf text 合同.pdf -o 合同.txt
```

**画成图片**：每页存成一张 PNG。`--dpi` 越大越清楚，默认是 150。

```
qingpdf render 合同.pdf --pages 1-3 --dpi 150 -o 第%d页.png
```

**图片转 PDF**：每张图片一页，按写的顺序排。默认放在 A4 纸上；加 `--page fit` 则页面大小和图片一样。

```
qingpdf img2pdf 第一张.jpg 第二张.png -o 图片合集.pdf
```

**加水印**：加文字水印。`--tile` 铺满整页，`--angle` 设角度，`--opacity` 设透明度（0 到 1），`--under` 垫在页面内容下面，`--pages` 指定页。也可以用 `--image 水印.png` 加图片水印。

```
qingpdf watermark 合同.pdf --text "机密" --opacity 0.3 --angle 45 --tile -o 加水印.pdf
```

**页码和页眉页脚**：给页面加页码、页眉、页脚：页眉和页脚各有左、中、右三处，一共六处文字（`--header-left`、`--header-center`、`--header-right`、`--footer-left`、`--footer-center`、`--footer-right`）。一处都不写，就是页脚中间写 `{page}`。文字里的 `{page}`（页码）、`{pages}`（最后一页的页码）、`{date}`（今天的日期，命令行按 UTC，和电脑上的日期有时差一天，阅读器用电脑上的日期）、`{file}`（文件名）会换成真的内容。`--size` 字号（默认 10.5），`--color` 颜色（六位十六进制，默认 000000），`--margin` 离页边的距离（毫米，默认 15），`--pages` 指定页（页码从范围里的第一页算起），`--start` 第一页的编号（默认 1），`--mirror` 第 2、4、6…页左右互换（双面打印时页码在外侧），`--skip-first` 范围里的第一页不写（仍算一页）。输出是原文件加一段追加的内容，原文件的字节原样保留；再运行一次会再加一套。

```
qingpdf pagenum 报告.pdf --footer-center "第 {page} 页 共 {pages} 页" -o 带页码.pdf
qingpdf pagenum 公文.pdf --footer-right "- {page} -" --mirror --size 14 --margin 25 -o 公文带页码.pdf
qingpdf pagenum 论文.pdf --header-right "{file}" --footer-center "{page}" --pages 3- --start 1 -o 论文带页码.pdf
```

**盖图片**：把签名或图标等图片放到指定页。`--at` 是图片左下角的位置，`--width` 是宽度，单位都是点（1 英寸 = 72 点）。

```
qingpdf stamp 合同.pdf --image 签名.png --page 3 --at 72,100 --width 120 -o 盖章后.pdf
```

**加文字**：在指定页的指定位置加一段文字。`--at` 是第一行文字的左下角位置，`--size` 是字号（点）；文字里写 `\n` 可以换行。

```
qingpdf addtext 合同.pdf --page 1 --at 72,720 --size 12 --text "你好" -o 加字后.pdf
```

**替换文字**：把页面上的“旧词”改成“新词”，只在一行之内找，不跨行。旧字仍在文件前面的内容里；要彻底去掉，再用 `qingpdf split 改字后.pdf --pages 1- -o 干净版.pdf` 重写一遍。

```
qingpdf replace 合同.pdf --find "旧词" --replace "新词" --pages 1-3 -o 改字后.pdf
```

**转 Word**：把页面转成可以编辑的 Word 文件。

```
qingpdf docx 报告.pdf --pages 1-10 -o 报告.docx
```

**转 Excel**：把页面里的表格转成 Excel 文件，一个表格一个工作表。

```
qingpdf xlsx 对账单.pdf --pages 1-10 -o 对账单.xlsx
```

## 5. 已知限制

1. **只有 Windows 版。** 阅读器和命令行工具都只能在 Windows 上运行。
2. **只认横排文字。** 文字识别只认横排。竖排的老书扫描件识别出来会是跨栏的横行，顺序会乱。
3. **没有框线的表格可能认不准。** 转 Excel 和 Word 时，没有框线的表靠文字对齐找出来。两列的“名称 | 说明”这类表、列间距很紧的表认不出来；有的图也可能被当成表。
4. **改字有限制。** 一次只改一行，跨行的段落不能一起改；有些重复使用的表单里的字也改不了。改完的旧字仍在文件的旧版本里，要彻底去掉，请用“另存为”。
5. **有签名的文件不能改内容。** 加水印、加页码、加图片、加文字、改字、旋转/删除/调顺序/插入页都会被拒绝。“签名图片”只是把图片放上去，不是数字签名；本程序不能签名，也不能验证签名。
6. **转成的 Word 和 Excel 不是原样复制。** Word 文件是可以编辑的版面，不会和原页一模一样；图表和绘制的图形不会转过去。
7. **加密只写 AES-256 和 AES-128。** 不写 RC4（太弱）；证书（公钥）加密不支持；打开的老文件里的 RC4 照样能读。AES-128 的文件密钥是按标准由密码、权限和文件编号算出来的，不是随机的（标准就这么定的），每个字符串和数据流的初始向量仍然是随机的。加密写的是新文件，不是在原文件后面追加。
