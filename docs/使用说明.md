# qingpdf 使用说明

## 1. 是什么

qingpdf 是一个小、快、离线的 PDF 工具。它不用安装，不联网，也不收集任何数据。

它包括两个程序：

- **qingpdf-view.exe**：阅读器。用来看 PDF，也可以批注、填表、改字、导出 Word 和 Excel。
- **qingpdf.exe**：命令行工具。用几条命令合并、拆分、加水印等，适合一次处理很多文件。

两个程序都只有几 MB。目前只支持 Windows。

## 2. 下载和打开

1. 把 zip 压缩包解压到一个文件夹（右键 → 全部提取）。
2. 双击 **qingpdf-view.exe**。
3. 按 Ctrl+O 选择 PDF 文件，或者直接把 PDF 拖进窗口（可以一次拖好几个，每个文件一个标签）。

第一次运行时，Windows 可能提示“已保护你的电脑”。这是因为程序没有付费签名，不是程序有问题。点“更多信息”，再点“仍要运行”即可。

如果菜单是英文的，点菜单 View（视图）→ Language（语言），选“中文”，马上生效。窗口的大小和位置、语言、工具栏、侧栏的标签和宽度、界面颜色、页面颜色，下次打开时会记住。

## 3. 阅读器怎么用

菜单在窗口顶部，菜单下面是工具栏（“视图 → 工具栏”可以隐藏它）。按 Esc 可以停止打印、导出、压缩和文字识别。

### 文件

| 功能 | 快捷键 | 做什么 |
|---|---|---|
| 打开 | Ctrl+O | 选一个 PDF 文件，在一个新标签里打开（这个文件已经开着，就切到它的标签） |
| 最近打开 | — | 列出最近打开过的文件；“清空列表”删掉这些记录，也删掉“上次看到哪一页”的记录 |
| 关闭标签 | Ctrl+W（Ctrl+F4） | 关掉现在这个标签；有没保存的改动会先问 |
| 保存 | Ctrl+S | 把你做的改动保存到这个文件 |
| 另存为 | Ctrl+Shift+S | 存成另一个文件，并整个重写一遍，改掉的旧字不会留在新文件里 |
| 导出为 Word | — | 转成可以编辑的 Word 文件（.docx） |
| 导出为 Excel | — | 把表格转成 Excel 文件（.xlsx），一个表格一个工作表 |
| 密码和权限 | — | 看这个文件现在怎么加密、限制了什么；设打开密码和权限密码，选 AES-256 或 AES-128，关掉打印、复制等权限，或者去掉密码（见下面“设密码和权限”） |
| 压缩 | — | 把文件变小，存成一个新文件（见下面“压缩文件”） |
| 打印 | Ctrl+P | 打印当前文件 |
| 退出 | — | 关闭阅读器；有几个标签带着没保存的改动，就一个一个问 |

**多个文件（标签页）：** 同时打开两个或更多文件时，页面上方出现一排标签（只有一个文件时没有这一排）。每个标签写着文件名，没保存的改动用橙色圆点标出，右边的 × 关掉它；鼠标放在标签上，会显示这个文件的完整路径。

- **切换：** 点标签，或按 Ctrl+Tab（下一个）、Ctrl+Shift+Tab（上一个），也可以用“转到”菜单；中键点标签关掉它。窗口标题永远是现在这个文件。
- **每个标签自己记着：** 看到哪一页、放大多少、转了多少、滚到哪里、侧栏停在哪个标签、选中的文字、没保存的改动和撤销记录。批注、保存、导出、打印、搜索、识别文字等等都只对现在这个标签做。
- **最多 16 个。** 再开会提示先关一个。
- **怎么开：** Ctrl+O、最近打开、把文件拖进窗口、命令行里写几个文件、在资源管理器里用 qingpdf-view 打开文件。已经有一个阅读器开着时，再用它打开一个 PDF（或从命令行再启动一次）不会开第二个窗口：文件交给开着的那个窗口，在新标签里打开，窗口回到最前面，新启动的程序马上退出。要关掉这个行为，在设置文件（`%APPDATA%\qingpdf\author.txt`）里加一行 `single_window=0`。拖进来的不是 PDF 或者读不了的文件，会有一条消息说是哪些（最多列出 8 个名字，其余只说有多少），别的什么也不做；一次拖进来的文件只看前 32 个，设备路径（`\\.\pipe\…`、`\\?\…`）一律不看；文件所在的网络位置不回答，最多等 2 秒，那个文件当作读不了。
- **正忙的标签不能切走：** 这个标签正在保存、导出、压缩、改密码、识别文字、打印、插页或者正在打开文件时，切换会提示“这个标签正忙”（按 Esc 可以停下识别、导出等）；正在打开文件时点别的标签，会等打开完再切过去。关掉一个正忙的标签没问题，它的任务一起取消。
- **内存：** 总共仍在 200 MB 之内。现在这个标签用得最宽松；别的标签只留着文件本身、没保存的改动，和刚才看到的那一屏清晰的画面（所有标签合起来最多 40 MB），所以切回最近用过的几个标签是马上出现的。标签太多、内存放不下时，没有未保存改动、也没用密码打开的标签会被放掉文件，再点它的时候从磁盘重新读（回到原来的页和放大，几十到一百多毫秒）；如果这个文件在那之间被改过，会告诉你，显示的是现在的内容；文件没了也会告诉你。带着没保存改动或用密码打开的标签不会被放掉，放不下新文件时会提示“先保存或关闭一些标签”。
- **回到上次看到的地方：** 打开一个以前看过的文件，会回到上次的页、放大、滚动位置和旋转（最近 200 个文件；文件被别的程序改过——大小或修改时间变了——就当新文件，从第一页开始）。记录在 `%APPDATA%\qingpdf\places.txt`，只有数字和路径，没有密码也没有文件内容。不想要的话，在设置文件里加一行 `remember_place=0`。

**打开加密文件：** 文件需要密码时，窗口会要你输入；密码不对会再问一次。只限制打印、复制的文件不用密码就能打开。如果作者不允许复制、打印、批注、填表或修改，相应的功能会提示“需要所有者密码”。所有者密码是作者设的管理密码，一般人没有，所以这些功能用不了。

**设密码和权限：** 文件 → 密码和权限…，窗口最上面一栏写着这个文件现在的保护（加密方式、打开要不要密码、哪些权限被关了）。下面可以设：

- **打开密码**：要打开文件就得输入的密码，各输两遍；留空是不需要密码。
- **权限密码**（所有者密码）：能解除下面所有限制的密码，各输两遍；留空是和打开密码一样。**只要关了任何一项权限，就必须设权限密码**，否则别人一个选项就能把限制打开，等于没限制。
- **加密方式**：AES-256（推荐，新的 PDF 阅读器都认）或 AES-128（给很老的软件用）。AES-128 的密码只能用拉丁字母，最多 32 个；有汉字的密码请用 AES-256（最多 127 个字节，一个汉字占 3 个）。
- **权限**：打印（允许高质量 / 只允许低质量 / 不允许）、复制文字和图片、修改内容、加批注、填写表单、插入删除旋转页面、为读屏软件提取内容。
- **去掉密码**：点窗口左下角的按钮，不带任何密码保存一份。

点“保存…”后选存到哪里：默认是这个文件本身（Windows 会问是不是覆盖），也可以另存一个新名字。保存是把整个文件重写一遍，**还没保存的改动一起存进去**，写完后自动重新打开（用权限密码打开，所以你接着是有全部权利的；以后别人打开时才受限制）。文件已经加密、又被作者限制了权限的，要先用所有者密码打开才能改；有数字签名的文件改不了（重写会弄坏签名）。**密码忘了没办法找回**，请自己记好。

注意：带遮挡的密码框里，Windows 常常不让中文输入法工作，要输中文密码可以从别处复制了粘贴进来。

**压缩文件：** 文件 → 压缩…，选一档，点“压缩…”，再选存到哪里（默认是这个文件旁边，名字后面加“-压缩”）。压缩在后台做，状态栏显示进度，**按 Esc 可以停**；做完会告诉你前后各多大，问要不要打开新文件。原文件不会改动。

- **每一档都会做的（不损失任何东西）：** 没人用的内容不写进新文件；重复的内容只存一份（每页都带一份的字体、图片、颜色配置文件、资源）；对象打包成对象流、目录表改成压缩的交叉引用流（PDF 1.5；文件自己说是 PDF/A-1 的不打包，写成传统的目录表，因为那个标准不许用对象流，压缩时会说一声）；数据流用最强的 Flate 重新压一遍，没压过的压上；去掉页面缩略图、做这个文件的程序留下的私有数据、页面和图片上的元数据（整份文件的元数据和文档信息留着）。
- **图片（三档的区别）：** 图片画得比这一档的“每英寸点数”还精细时，缩到那个大小再存成 JPEG，只在结果更小时才换。**高质量**：200 dpi，JPEG 质量 85；**平衡**：150 dpi，质量 75（默认）；**最小**：100 dpi，质量 60。图片缩到多大，看它在哪一页画得最大（页面、表单、批注的外观都查）。勾上“只做无损压缩”就只做上面那一条，图片一点不动。
- **不动的图片：** 黑白图和蒙版（只重新压缩）；带 `/Decode` 或颜色键蒙版的、CMYK 的、索引颜色的、16 位的；平铺图案、Type 3 字形、软蒙版组里画的图。带软蒙版的图，蒙版跟着缩到同样大小。
- **永远不会变大：** 压完不比原来小，就不生成新文件，并告诉你。
- **加密文件：** 新文件保持原来的加密（同样的方法、同样的密码）。作者不允许修改内容的文件，要缩小图片得用所有者密码打开；只做无损压缩（勾上“只做无损压缩”）不需要，和转页、删页一样；有数字签名的文件不能压缩（重写会弄坏签名）。
- **没保存的改动：** 压缩前会问要不要先保存；不保存就不压缩。超过 30 MB 的文件阅读器里不压缩（占内存太多），窗口很大（比如 4K 屏）时约 16 MB 以上的文件也不行，会告诉你；请用命令行。

### 编辑

| 功能 | 快捷键 | 做什么 |
|---|---|---|
| 撤销 | Ctrl+Z | 撤销上一步改动，保存以后也能撤销 |
| 重做 | Ctrl+Y | 把撤销的那一步再做一遍 |
| 复制 | Ctrl+C | 复制选中的文字 |
| 查找 | Ctrl+F | 输入要找的字，回车找下一处；全角和半角、大小写都当作一样 |
| 查找下一个 | F3 | 找下一处 |
| 查找上一个 | Shift+F3 | 找上一处 |

工具栏上也有搜索框，输入后按回车就能找。

### 视图

| 功能 | 快捷键 | 做什么 |
|---|---|---|
| 放大 | Ctrl++ | 放大页面 |
| 缩小 | Ctrl+- | 缩小页面 |
| 适合宽度 | Ctrl+1 | 页面宽度正好填满窗口 |
| 适合整页 | Ctrl+2 | 整页正好放进窗口 |

| 页面布局 | — | 子菜单，选一种：“单页连续”（一页接一页，平常的样子）、“双页”（两页并排：1、2；3、4……）、“双页（封面单独）”（第一页自己一行，然后 2、3；4、5……）。每个文件各记各的，下次打开还是这样；一个文件以前没打开过时，按文件自己的设置来（PDF 里写了“两栏”就是双页，写了“第一页在右、单独一页”就是封面单独，写了“从右往左”的竖排书两页的左右也反过来），文件什么也没写就用你上次选的。双页时两页的中缝在同一条竖线上，页的大小不一样也对得齐，矮一点的页在行的正中；缩放、查找、划选、批注、书签、缩略图（两页都有蓝框）、页码框和 Ctrl+G 都照常。上一页、下一页按钮和 Ctrl+PgUp、Ctrl+PgDn 一次走一行（两页）；状态栏写“第 2-3 / 120 页” |
| 全屏 | F11 | 窗口没有边框、菜单、工具栏、标签条、侧栏和状态栏，页面铺满窗口所在的那台显示器。Esc 或再按 F11 回来，窗口原来是什么样（大小、位置、最大化）就回到什么样 |
| 放映 | F5 | 一次一页，整页放进屏幕，黑色背景（每页按自己的大小放，大小不一样的扫描页也行）。单击、空格、PgDn、→、↓、回车翻到下一页；Backspace、PgUp、←、↑、Shift+空格、鼠标右键回到上一页；滚轮一格一页；Home、End 到第一页、最后一页。页面上的链接可以点。鼠标停 2 秒就藏起来，一动又出现。Esc 结束，停在放映到的那一页，缩放回到放映前。放映时下一页和前一页已经在后台画好，翻页是立刻的 |
| 界面 | — | 子菜单：“跟随系统”（读 Windows 的“应用模式”，系统改了它也跟着改）、“浅色”、“深色”。深色时标题栏、工具栏、标签条、侧栏（书签、缩略图、批注清单）、状态栏、页码框和搜索框、页面周围的底色都变暗。**不变的：** 菜单栏和弹出菜单、对话框（打开、保存、打印、密码框、各种设置框）、鼠标提示，它们用 Windows 自己的样子（Windows 没有给程序改这些的公开办法）；滚动条是 Windows 自己的控件，在 Windows 11 上会随标题栏一起变暗，别的版本不保证 |
| 页面颜色 | — | 子菜单：“原色”（文件原来的颜色）、“夜间”（明暗反过来、色相不变：白纸变近黑，黑字变浅灰，黄色高亮仍是黄色，蓝字仍是蓝字）、“护眼”（白纸变暖黄色 #F4ECD8，字仍是黑的）。**只改屏幕上看到的**：打印、导出、复制文字、保存的文件都不变；缩略图跟着变；选中的字、查找到的字、批注的框和手柄在每种颜色下都看得清。图片也会跟着变（夜间时照片像底片），要看原图就选“原色” |
| 工具栏 | — | 显示或隐藏工具栏 |
| 语言 | — | 选“跟随系统”“中文”或“English”，马上生效 |

设置文件（`%APPDATA%\qingpdf\author.txt`）里还记着三行：`theme=`（`system`、`light`、`dark`）、`page_color=`（`original`、`night`、`sepia`）、`layout=`（`single`、`spread`、`cover`：文件以前没打开过、也没写排版时用的）；都是菜单一选就改，没改过就不写。

### 批注

批注是盖在页面上的标记，不会改动原来的字。

| 功能 | 快捷键 | 做什么 |
|---|---|---|
| 选择 | Esc | 回到普通状态，可以选字 |
| 高亮 | — | 拖过要标记的文字，给它涂上颜色 |
| 下划线 | — | 给拖过的文字加下划线 |
| 删除线 | — | 给拖过的文字加删除线 |
| 波浪线 | — | 给拖过的文字加波浪线 |
| 手写 | — | 按住鼠标拖动来画 |
| 矩形、椭圆 | — | 按住鼠标拖出一个矩形或椭圆；按住 Shift 拖，得到正方形或正圆。边框用“颜色”和“线宽”，勾上“填充”就用同一种颜色的浅色填满（下面的字还看得见） |
| 直线、箭头 | — | 按住鼠标从一端拖到另一端；按住 Shift 拖，角度停在 45° 的整数倍上。箭头的头在松开的那一端 |
| 便签 | — | 点一下放便签的位置，然后输入便签文字 |
| 文字框 | — | 拖出一个框，在里面输入文字；点框外或按 Ctrl+Enter 完成，Esc 结束 |
| 签名图片 | — | 选一张 PNG 或 JPEG 图片（比如签名的图片），拖动移动，拖角缩放，按 Enter 放好，Esc 取消 |
| 颜色 | — | 选批注的颜色：黄、绿、蓝、粉、红、黑。选中了一个批注时，改的是这个批注（它是高亮、下划线、删除线、波浪线、手写、矩形、椭圆、直线、便签或文字框才行，别的种类这几项是灰的）；没选中批注时，改的是以后加的 |
| 线宽 | — | 选细、中、粗、特粗。同上，选中了手写、矩形、椭圆或直线时改的是它 |
| 填充 | — | 矩形、椭圆是否填充。选中了矩形或椭圆时改的是它 |
| 字号 | — | 文字框的字号：小（10 磅）、中（12 磅）、大（16 磅）、特大（24 磅） |
| 作者名 | — | 设置你加的批注上署的名字 |
| 删除批注 | Del | 选中批注后删除（Ctrl+Z 可以撤销）。作者锁定的批注（`/F` 的 Locked 位）删不掉 |

**改已经有的批注（我们加的、别的软件加的都行）：**

| 做什么 | 怎么做 |
|---|---|
| 选中 | 在“选择”状态下点一下。选中的批注有蓝框，能缩放的有四个角上的小方块；状态栏说它是什么、谁写的、写了什么。点到链接和表单字段时，链接和字段优先；高亮这类标在文字上的，拖过它是选字，点一下才是选中它 |
| 移动 | 拖选中的批注（或者直接拖一个不是标在文字上的批注）；方向键每次动 1 点，按住 Shift 每次动 10 点（连按的方向键算一次移动，Ctrl+Z 一次撤销） |
| 缩放 | 拖四个角上的小方块。矩形、椭圆、直线、手写、文字框、图片和多边形能缩放，便签的图标和标在文字上的高亮等不能；图片始终保持原来的形状，别的按住 Shift 保持形状。形状和文字框是重画的（线宽、字号不变），图片等是拉伸 |
| 改颜色、线宽、填充 | 选中后用“颜色”“线宽”“填充”菜单 |
| 改文字 | 双击便签：弹出框里改；双击文字框：在原处改（Ctrl+Enter 或点框外完成，Esc 放弃）。作者锁定了文字（LockedContents 位）的不能改 |
| 锁定的批注 | 作者锁定（Locked 位）的批注可以选中、改文字（文字框的框不变，字排不下就不改），但不能移动、缩放、改颜色、删除；设成只读的什么都不能改；状态栏会说“这个批注已锁定” |
| 别家批注改不了的 | 会丢东西的不重画，只能移动：虚线、云边、有引线或说明文字的直线、别的箭头样式、Acrobat 那种带富文本、边框或底色的文字框、别的图标的便签、半透明的文字框；超过 4000 字的文字不能在这里改。移动时回复它的批注和弹出框跟着走 |

所有这些都能 Ctrl+Z / Ctrl+Y，保存时和别的批注写成同一次追加；有“认证”签名的文件，只有认证级别为 3 的才许改批注，1 和 2 会拒绝；文件作者不许批注的，要所有者密码。

**批注清单（侧栏的第三个标签“批注”）：** 一页一个标题（“第 3 页”），下面每个批注一行：种类和作者、第一行文字、最后修改的时间。不列链接、表单控件、弹出框和隐藏的。点一行跳到那页并选中这个批注；↑ ↓ PgUp PgDn Home End 在清单里移动；Delete 删除选中的批注（锁定的不删）；右边的细条可以拖。没有批注时清单里会这样说。几千个批注也不慢；清单最多列 2 万个，每页最多 2000 个，多了会提示。

### 插入

这些功能会把内容写进页面本身，打印和别的软件也能看到。

| 功能 | 做什么 |
|---|---|
| 添加书签 | Ctrl+B。在窗口顶上这一处加一个书签（见下面“编辑书签”），不改页面内容 |
| 加文字 | 在页面上加一段文字（支持中文） |
| 加图片 | 选一张 PNG 或 JPEG 图片，放到页面上 |
| 加水印 | 输入水印文字，可以设透明度和角度；可以平铺满页，可以垫在页面内容下面，也可以只加在当前页 |
| 页码和页眉页脚… | 一个窗口：页眉、页脚各有左、中、右三处，一共六处文字，每处点下拉箭头可以挑常用的写法（`{page}`、`第 {page} 页`、`第 {page} 页 共 {pages} 页`、`- {page} -`、`{page} / {pages}`、`Page {page} of {pages}`），也可以自己写；可以设字号、颜色、离页边的距离（毫米）、从第几页到第几页（不填是全部）、起始编号（例如从第 3 页起写 1）、单双页对称（双面打印时页码在外侧，公文的写法）、首页不加。右边的小图随着输入显示当前这一页的样子。窗口里的“删除已有的页码和页眉页脚”只删本程序加的那些。可以撤销，保存时和别的改动写成同一次追加 |
| 改页面上的文字 | 点一行文字，输入新的内容，按回车确认（Esc 取消）。原来的字会从页面里去掉 |

**页码和页眉页脚的字段：** 文字里写 `{page}` 是这一页的页码，`{pages}` 是最后一页的页码（整份文件从 1 起编，就是总页数），`{date}` 是今天的日期（例如 2026-10-15，阅读器用电脑上的日期），`{file}` 是文件名（不带文件夹）；别的字照原样写出来。

**页码注意：**

- 页码和页眉页脚是写进页面的，打印和别的软件也看得到；它们标成页面的页眉和页脚（不算正文），所以提取文字、查找、复制、导出 Word 和 Excel 都不含它们。
- 页码从范围里的第一页算起：范围是第 3 页到最后、起始编号写 1，第 3 页就是 1。选了“首页不加”，范围里的第一页不写，但仍算一页（下一页是 2）。
- “单双页对称”按页在文件里的位置：第 2、4、6…页是左页，这几页上左、右两处的文字互换，中间的不动。要页码在外侧，就把它写在右边。
- 再用一次会再加一套；要换成新的，先点“删除已有的页码和页眉页脚”。它只认本程序加的，别的软件加的页码删不掉，别的软件改写过文件之后也可能认不出来（认不出来就不动）。删除之后字体仍在文件里（几 KB）。
- 文字需要的字都得在系统字体里找得到，找不到会说哪个字没有。有签名的文件、作者不允许改内容的文件不能加（和加水印一样）。

**改字注意：** 一次只能改一行，跨行的段落要分开改。新字比原来宽时，会提示可能压到后面的字。改完后旧字仍留在文件的旧版本里，要彻底去掉，请用“另存为”。

### 涂黑

涂黑是把不想让人看到的内容**真正删掉**，不是在上面盖一块黑。用法是两步：先标记（页面上出现红框，这时内容都还在），再“应用涂黑”（红框里的内容被删掉，原处是一个黑框）。

| 功能 | 做什么 |
|---|---|
| 标记区域（拖出方框） | 一个工具：按住鼠标拖出一个方框，松开就做一个标记；Esc 结束。可以框文字，也可以框图片、扫描页上的字 |
| 标记所选文字 | 先选中文字，再点这一项：每行字一个红框，跨页的选择每页各做一个 |
| 查找并标记… | 一个窗口：输入要找的词（大小写、全角半角不分），或者勾“身份证号”“手机号”“银行卡号”，在**全部页**里找到的**每一处**都做一个标记；批注和表单字段里说的话（备注、字段的值、自由文本，连同它们外观里画的字）也找，找到的做一个盖着那个批注的标记。状态栏说标记了几处；一处也没有就什么也不做；有读不全的页（太大、字体不在、内容流读不了）会在一个提示框里说页码。一次最多 5000 处 |
| 应用涂黑… | 一个窗口：说明后果（见下），可以填“盒子上的字”（例如“已涂黑”，空着就不写），可以勾“同时清除文档信息和元数据”和“同时删除附件和脚本”。点“应用…”后选存到哪里：默认是这个文件旁边的“名字-涂黑.pdf”；选原文件就是覆盖它（Windows 会先问）。做完新文件在一个新标签里打开（覆盖原文件时，原来的标签换成新文件），有要提醒的（见下“留在文件里的东西”）在一个提示框里说；原来的文件不改动 |

**标记是批注**（种类叫“涂黑标记”）：批注清单里有，可以点选、按 Delete 删除、Ctrl+Z 撤销；保存时和别的批注一起写进文件（别的软件也认这种批注），以后再打开还能接着应用。红框里的字和图仍然看得见，淡淡染了红色。

**应用涂黑真的删什么：**

- **文字：** 方框碰到的每个字（只要字的格子和方框有重叠）都从页面内容里删掉，包括看不见的字（扫描页的识别文字层、渲染模式 3）、表单对象里的字、水印和页码；方框外面的字原地不动（同一行里后面的字不会往前挤）；没有 `/Widths` 的标准字体（Helvetica 等）字宽是猜的，不知道字在哪里：这样的字体，标记碰到的那一行，**整行字（那条命令里的所有字）都删**，不是只删框里的。标记内容里的 `/ActualText`、`/Alt`、`/E`（读文字的程序和读屏软件会从那里读）：有标记的页上**全部**去掉，不管写在语句里、写在资源的 `/Properties` 里，还是写在结构树里指向这一页的元素上。字体不在页面资源里（或根本没选字体）的文字读不出来，也就删不了：这一页**整个失败**并说页码。没有自己 `/Font` 资源的表单对象，用画它的页的字体（和 PDFium 一样）。
- **图片：** 方框下面的像素在图片自己里涂成框的颜色，再按原样编码（JPEG 图片仍是高质量 JPEG，别的用 Flate）；图片的透明蒙版、软蒙版也一起处理；页内的小图（内联图）变成图片对象；同一幅图画在几处时，每处各改各的，不动原来那幅。读不懂的图片（没法解码）整幅不画。
- **图形：** 完全在方框里面的线条、矩形、图形不再画；**只有一部分在方框里的图形保持原样**（它被黑框盖住一部分，没有被改掉）。
- **批注和表单：** 和方框重叠的批注（链接、便签、高亮等）和表单控件从页面上去掉，便签的弹出框和对它的回复跟着去掉，表单控件连同它的值一起从表单里去掉；有表单控件被去掉时，文件的 XFA 数据（里面有表单的值）也去掉。
- **图案：** 不再有东西用它画的图案（它画的路径都被删了，别的东西也没用过它；里面可能有字）从资源里去掉。
- **之后：** 在原处画黑框（颜色用标记的颜色，可以带字），去掉标记，页面的缩略图和页面自己的元数据丢掉；一页的内容分在几个内容流里的，写成一个流（语句从一个流跨到下一个也照删）；整份文件**重新写一遍**，只留够得着的对象（旧内容不在新文件里），加密的保持原来的加密。

**这些不会被删（会报告，见下）：** 书签标题、命名目的地的名字、附件（文件和它们的说明）、脚本（JavaScript）、别的页上的批注和表单字段里的字、结构树里没有指向有标记的页的元素的说明文字、文档信息和元数据（没勾“同时清除”时）。**也不会被删（有 `/ToUnicode` 表的字体会提示一句）：** 字体文件（里面有字形，没有字的顺序）和字体的 `/ToUnicode` 表（字码对应的字，删过字的字体里仍列着那些字：两三个字的名字可以从里面读回**一组字，不带顺序**）；Type 3 字形、软蒙版组里画的图；只有一部分在框里的图形（见上）。有这些担心时，先用“文件 → 压缩…”、转 Word 等别的办法检查，或把整页删掉。

**留在文件里的东西会报告：** 应用之后，程序在新文件里把上面这些地方找一遍，看被删掉的字（被删的连续的字，两个字以上；再加上你查的词）还在不在，在的**每一处地方都说**（阅读器里是一个提示框，命令行是 `warning:` 行）：它们不是页面上的内容，涂黑不改，要自己改或删。文件里有几个附件、几个脚本也总是说（有就说）；勾“同时删除附件和脚本”（命令行 `--remove-attachments`）就把它们删掉：文档目录里的附件和脚本名字树、打开文件时的动作、文档和页面和批注（包括表单控件）上的脚本动作、关联文件；带附件的批注变成空的小批注。表单字段自己的动作（不是控件批注上的）不处理。

**要什么权利：** 文件作者没有允许“修改内容”（权限位 4）又没用所有者密码打开的，不能应用（标记只需要“批注”的权利）；有签名的文件拒绝（整份重写会弄坏签名）。

### 管理页面（缩略图栏）

在“缩略图”标签里选页，再旋转、删除、调顺序、插入、提取。所有操作都可以用 Ctrl+Z / Ctrl+Y 撤销、重做（和批注、改字在同一条撤销记录里）。

| 做什么 | 怎么做 |
|---|---|
| 选页 | 点一张选一页；Ctrl+点 加选或去掉；Shift+点 选一段；在缩略图栏里按 Ctrl+A 全选。选中的页有蓝底 |
| 向左 / 向右旋转 | 右键 → 向左旋转、向右旋转，或 Ctrl+[ 、Ctrl+]（改的是页面自己的 /Rotate，保存后别的软件看到的也是转过的） |
| 删除 | 右键 → 删除，或在缩略图栏里按 Delete。不能删光所有页。删掉页上的表单字段一起去掉；书签和链接指向被删的页时点了没反应 |
| 调顺序 | 按住选中的页拖到新位置，橙色横线是放下的位置；拖到栏的上下边缘会自动滚动；Esc 取消 |
| 从文件插入页 | 右键 → 从文件插入页：之前 / 之后…，选一个 PDF，把它的全部页插进来（带批注、表单字段、链接；不带书签；字段重名会自动改名；对方文件里的数字签名不带过来，签名字段留着但是空的）。文件不能超过 16 MB，也不能超过没保存的改动剩下的内存，放不下时提示先保存文件或者换小一点的文件。要密码的文件会问密码；权限不全（有任何限制）又没给所有者密码的文件会被拒绝，和命令行合并的规矩一样 |
| 提取为新 PDF | 右键 → 提取为新 PDF…，把选中的页写成一个新文件（不碰正在看的文件；有加密的保持原来的加密）。文件作者不许复制时不能提取 |

保存（Ctrl+S）是增量保存：新的页面树、转过的页、插进来的页追加在原文件后面，原文件的字节原样留着，所以**删掉的页仍在保存后文件的旧版本部分里**；要真正去掉，用“另存为”（整个文件重写）。文件作者不许“拼装”页面（权限位 11）又没用所有者密码打开时，这些命令是灰的；有签名的文件不能改页。

### 编辑书签（侧栏“书签”标签）

书签（目录）可以直接在侧栏里改。所有操作都可以用 Ctrl+Z / Ctrl+Y 撤销、重做（和批注、改字、管理页面在同一条撤销记录里），保存（Ctrl+S）时只追加改过的书签对象，原文件的字节原样留着。右键点书签（或空白处）有一个菜单，列着下面这些。

| 做什么 | 怎么做 |
|---|---|
| 添加书签 | Ctrl+B（侧栏里点过之后也行），或右键 → 添加书签。加在窗口顶上这一处，放在选中的书签（连同它下面的）后面，同一级；没选中就加在最后。**书签的名字：** 先看有没有选中的文字，有就用它；没有就用这一页上离这个位置最近的标题（按“转 Word”认标题的办法认）；页上没有标题就叫“第 N 页”。没有书签的文件，加了第一个书签后侧栏自动打开“书签”标签 |
| 重命名 | F2，或右键 → 重命名；也可以在选中的书签上隔一会儿再点一下。在原处改，中文输入法照常用，回车确认，Esc 取消；名字最多 300 字，空的不接受；没有名字的书签在树里显示“（无标题）”，在它的框里直接回车（没改字）不算改动 |
| 删除 | Delete，或右键 → 删除。连它下面的书签一起删，可以撤销 |
| 拖着调顺序、调层次 | 按住书签拖：落在一行的上三分之一是放到它前面（黑横线），下三分之一是放到它后面（黑横线；这一行展开着时是放到它第一个子书签前面），中间是放到它里面（这一行变蓝）；带着下面的书签一起走。拖到侧栏上下边缘会自动滚动；Esc 取消。不能拖进它自己的下面，也不能超过 32 级 |
| 降级 / 升级 | Tab / Shift+Tab，或右键 → 降级、升级。降级是变成它前面那个书签的子书签；升级是上提一级，位置不动（原来排在它后面的同级书签变成它的子书签）。第一个书签不能降级，最上一级不能升级 |
| 设为当前位置 | 右键 → 设为当前位置：这个书签从此跳到窗口顶上这一处（`/XYZ 左 上 null`，不改缩放）。命名目的地换成明确的位置 |
| 展开、折叠 | 点书签前面的加减号；展开或折叠的状态保存成 `/Count` 的正负，在下一次改书签时一起写（只展开、折叠不会让文件变成“已修改”） |
| 自动生成书签 | 工具 → 自动生成书签…（也在右键菜单里）。468 页的书不到 1 秒 |

**别的书签动作不动：** 书签如果是链接（网址）、命名动作（如“下一页”）、跳到别的文件、脚本，改名字和调位置时它的动作原样保留，“设为当前位置”对它灰掉（要改位置，先在别的软件里处理）。命名目的地（`/Names`）一律不碰。

**权限：** 文件作者没有允许“拼装”（权限位 11）也没有允许“修改内容”（权限位 4），又没用所有者密码打开时，书签的命令都是灰的，右键菜单最上面一行说明原因，按 Ctrl+B 状态栏也会说；有数字签名的文件一律拒绝（和管理页面是同一条规矩，状态栏里写“signed”）。加密的文件改完仍是原来的加密，书签标题和别的字符串一起加密。

**写进文件的样子：** 标题能用 PDFDocEncoding 就用它，否则用带 BOM 的 UTF-16BE；每个书签有 `/Parent`、`/Prev`、`/Next`、`/First`、`/Last` 和 `/Count`（打开的是子书签的个数，合上的是负数），别的软件（PDFium、PyMuPDF、qpdf）都按同样的标题、层次、页码读出来。**限制：** 最多 20000 个书签、32 级、标题 300 字。超过这些的文件，侧栏只显示读到的前面那些，改它们会被拒绝（不然没读到的会丢）；“自动生成书签”和命令行的 `--import`、`--auto` 是整份换掉，照常能做。**另存为**或损坏的文件第一次改动会把整个文件重新写一遍，书签的对象号跟着变，侧栏会自己重新读一次书签，接着改不受影响。

### 页面上直接操作

- 拖动鼠标可以选中文字。双击选一个词（中文是到标点为止的一整段），三击选一行。
- 在页面上点右键，可以复制、高亮所选文字、在此添加便签、选择本页全部文字。
- **填表**：页面上的表单框，直接点进去填写。填错了按 Ctrl+Z 撤销。

## 4. 命令行工具

**怎么打开命令行窗口：** 在放着 qingpdf.exe 的文件夹里，点击窗口上方的地址栏，输入 `cmd`，按回车。弹出的黑色窗口就是命令行窗口。在里面输入下面的命令，按回车执行。

注意：

- 文件名中间有空格时，要用英文双引号括起来，例如 `"合同 终稿.pdf"`。
- 已经存在的输出文件不会被覆盖。要覆盖，就在命令最后加上 `--force`。
- 页码写法：`1-3,5` 是第 1、2、3、5 页；`8-` 是第 8 页到最后一页。
- 加密的文件，加上 `--password 密码`。

**查看信息**：显示页数、页面大小、文件信息，以及是否加密。

```
qingpdf info 合同.pdf
```

**合并**：按顺序把几个 PDF 接在一起。

```
qingpdf merge 合同.pdf 附件.pdf -o 合并.pdf
```

**拆分**：`--pages` 取出指定的页；`--every` 每 N 页切成一个文件，输出名里要有 `%d`，它会变成 1、2、3……

```
qingpdf split 合同.pdf --pages 1-3,5 -o 前三页和第五页.pdf
qingpdf split 合同.pdf --every 10 -o 第%d份.pdf
```

**删页**：删掉指定的页。

```
qingpdf delete 合同.pdf --pages 2,4-6 -o 删页后.pdf
```

**旋转**：把指定的页顺时针转 90 度；`--angle -90` 是逆时针。不写 `--pages` 就是全部页。

```
qingpdf rotate 扫描件.pdf --pages 1-3 --angle 90 -o 转正.pdf
```

**去掉加密**：写出一个没有密码的副本。只有知道所有者密码，或者文件本来允许一切操作时才能用；有签名的文件不行（整个文件重写会弄坏签名）。

```
qingpdf decrypt 加密合同.pdf -o 无密码合同.pdf --password 密码
```

**加密码、设权限**：写出一个加了密码、关了某些权限的副本，默认用 AES-256（`--aes128` 是 AES-128）。`--user-password` 是打开密码，`--owner-password` 是权限密码（只给打开密码时，权限密码和它一样）；密码也可以放在一个文本文件里用 `--password-file` 读（第一行是打开密码，第二行是权限密码，哪一行可以是空的），这样别人看不到你敲的命令里有什么；密码前后不能有空格，也不能有控制字符（在 cmd 里用 `echo 密码 > 文件` 写会在密码后多出一个空格，会被拒绝；请用记事本写，存成 UTF-8）。权限默认都开着，用这些选项关：`--print none|low|high`（不许打印 / 只许低质量 / 高质量），`--no-copy`（复制文字和图片）、`--no-modify`（修改内容）、`--no-annotate`（批注）、`--no-forms`（填表）、`--no-assemble`（插入、删除、旋转页面）、`--no-accessibility`（给读屏软件提取）；`--cleartext-metadata` 不加密文档的元数据（让搜索程序读得到）。关了任何一项权限必须给权限密码；一个密码也不给又不关任何权限，会拒绝（没有东西可保护）。输入文件已经加密的，用 `--password` 给它的密码，并且要有所有者的权利（和 `decrypt` 同一条规矩）；有签名的文件会被拒绝。输出是整个重写的新文件，不能和输入同名。密码不会出现在任何输出里。

```
qingpdf encrypt 合同.pdf -o 加密合同.pdf --user-password 打开用的密码 --owner-password 管理用的密码
qingpdf encrypt 报告.pdf -o 只读报告.pdf --owner-password 管理用的密码 --no-copy --no-modify --print low
qingpdf encrypt 合同.pdf -o 兼容旧软件.pdf --aes128 --password-file 密码.txt
```

要去掉密码，用上面的 `decrypt`；要换密码，对加密的文件再运行一次 `encrypt`（`--password` 给旧密码）。

**压缩**：写出一个更小的副本，并打印前后各多少字节。`--preset high|balanced|small` 选一档（默认 `balanced`：图片画得超过 150 dpi 就缩到 150 dpi，JPEG 质量 75；`high` 是 200 dpi、质量 85；`small` 是 100 dpi、质量 60），`--lossless` 只做不损失任何东西的那部分（图片不动）。每次都做：丢掉没人用的内容、合并重复的对象、打包成对象流和压缩的交叉引用流、数据流重新压到最强、去掉缩略图和私有数据。加密文件用 `--password` 给密码，新文件保持原来的加密；作者不允许修改内容的文件，缩小图片要给所有者密码，`--lossless` 不用；有签名的文件会被拒绝。**输出永远不会比输入大**：压完不比原来小，输出就是输入的一份拷贝，命令会明说。

```
qingpdf compress 扫描件.pdf -o 小扫描件.pdf
qingpdf compress 画册.pdf -o 画册小.pdf --preset small
qingpdf compress 合同.pdf -o 合同小.pdf --lossless
```

**提取文字**：按阅读顺序输出文字；不写 `-o` 就直接显示在窗口里。扫描件没有文字，要先在阅读器里识别。

```
qingpdf text 合同.pdf -o 合同.txt
```

**画成图片**：每页存成一张 PNG。`--dpi` 越大越清楚，默认是 150。

```
qingpdf render 合同.pdf --pages 1-3 --dpi 150 -o 第%d页.png
```

**图片转 PDF**：每张图片一页，按写的顺序排。默认放在 A4 纸上；加 `--page fit` 则页面大小和图片一样。

```
qingpdf img2pdf 第一张.jpg 第二张.png -o 图片合集.pdf
```

**加水印**：加文字水印。`--tile` 铺满整页，`--angle` 设角度，`--opacity` 设透明度（0 到 1），`--under` 垫在页面内容下面，`--pages` 指定页。也可以用 `--image 水印.png` 加图片水印。

```
qingpdf watermark 合同.pdf --text "机密" --opacity 0.3 --angle 45 --tile -o 加水印.pdf
```

**页码和页眉页脚**：给页面加页码、页眉、页脚：页眉和页脚各有左、中、右三处，一共六处文字（`--header-left`、`--header-center`、`--header-right`、`--footer-left`、`--footer-center`、`--footer-right`）。一处都不写，就是页脚中间写 `{page}`。文字里的 `{page}`（页码）、`{pages}`（最后一页的页码）、`{date}`（今天的日期，命令行按 UTC，和电脑上的日期有时差一天，阅读器用电脑上的日期）、`{file}`（文件名）会换成真的内容。`--size` 字号（默认 10.5），`--color` 颜色（六位十六进制，默认 000000），`--margin` 离页边的距离（毫米，默认 15），`--pages` 指定页（页码从范围里的第一页算起），`--start` 第一页的编号（默认 1），`--mirror` 第 2、4、6…页左右互换（双面打印时页码在外侧），`--skip-first` 范围里的第一页不写（仍算一页）。输出是原文件加一段追加的内容，原文件的字节原样保留；再运行一次会再加一套。

```
qingpdf pagenum 报告.pdf --footer-center "第 {page} 页 共 {pages} 页" -o 带页码.pdf
qingpdf pagenum 公文.pdf --footer-right "- {page} -" --mirror --size 14 --margin 25 -o 公文带页码.pdf
qingpdf pagenum 论文.pdf --header-right "{file}" --footer-center "{page}" --pages 3- --start 1 -o 论文带页码.pdf
```

**盖图片**：把签名或图标等图片放到指定页。`--at` 是图片左下角的位置，`--width` 是宽度，单位都是点（1 英寸 = 72 点）。

```
qingpdf stamp 合同.pdf --image 签名.png --page 3 --at 72,100 --width 120 -o 盖章后.pdf
```

**加文字**：在指定页的指定位置加一段文字。`--at` 是第一行文字的左下角位置，`--size` 是字号（点）；文字里写 `\n` 可以换行。

```
qingpdf addtext 合同.pdf --page 1 --at 72,720 --size 12 --text "你好" -o 加字后.pdf
```

**替换文字**：把页面上的“旧词”改成“新词”，只在一行之内找，不跨行。旧字仍在文件前面的内容里；要彻底去掉，再用 `qingpdf split 改字后.pdf --pages 1- -o 干净版.pdf` 重写一遍。

```
qingpdf replace 合同.pdf --find "旧词" --replace "新词" --pages 1-3 -o 改字后.pdf
```

**涂黑**：把页面上某些位置的内容真正删掉，原处画黑框。位置有三种写法，每种都可以写多次：`--find 文字`（页面上找到的每一处；大小写、全角半角不分）、`--pattern idcard|phone|bankcard`（身份证号：18 位、末位可为 X；手机号：11 位、13 到 19 开头；银行卡号：16 到 19 位，可以用空格或连字符分组；都不认一个更长的数字里面的一段）、`--area 页码:X,Y,宽,高`（页码从 1 起，X、Y 是方框左下角、单位点、从页面左下角量起，向右向上）；文件里已有的涂黑标记（阅读器做的）也一起处理。`--color 000000` 是框的颜色，`--label 文字` 是框上的字（例如 `已涂黑`），`--clear-metadata` 同时去掉文档信息和元数据，`--remove-attachments` 同时删掉附件和脚本。命令打印每一页删了多少字、图片、图形、批注；有 `--find` 或 `--pattern` 没找到的会警告；**一处位置都没有时退出码是 1，不写文件**。输出是整份重写的新文件（旧内容不在里面），不能和输入同名；加密文件要 `--password`（要有“修改内容”的权利或所有者密码），新文件保持加密；有签名的文件拒绝。一页里读不了的内容（不认识的过滤器）、读不出来的文字（字体不在页面资源里），整个命令失败并说页码，不会交出做了一半的文件。附件、脚本和还留着被删文字的地方（书签、名字、元数据……）会在 `warning:` 里说。

```
qingpdf redact 合同.pdf --find "张三" --pattern idcard --pattern phone --area 1:72,600,200,40 --label 已涂黑 -o 合同-涂黑.pdf
```

**转 Word**：把页面转成可以编辑的 Word 文件。

```
qingpdf docx 报告.pdf --pages 1-10 -o 报告.docx
```

**转 Excel**：把页面里的表格转成 Excel 文件，一个表格一个工作表。

```
qingpdf xlsx 对账单.pdf --pages 1-10 -o 对账单.xlsx
```

**书签**：`--export` 把书签写成文本文件，`--import` 用文本文件换掉书签，`--auto` 按页面上的标题生成书签（最多三级）。后两个写出的是在原文件后面追加改动的新 PDF（原文件的字节原样留着）。

```
qingpdf bookmarks 报告.pdf --export 目录.txt
qingpdf bookmarks 报告.pdf --import 目录.txt -o 新目录.pdf
qingpdf bookmarks 报告.pdf --auto -o 带目录.pdf
```

文本文件一个书签一行：行首每一级一个制表符，然后是标题，一个制表符，页码（从 1 数；这个书签不指向任何页就留空）。例如第一章在第 3 页、第一节在第 4 页：

```
第一章	3
	第一节	4
```

读入时带不带 BOM 都行，换行 CRLF 或 LF 都行，空行跳过。**层次只认制表符**（一级一个）；标题和页码两头的空白去掉。有毛病的行会报出行号：缺页码、页码不在文件里、标题是空的、标题以空格开头（多半是用空格写了层次）、标题里有制表符（行尾多一个制表符会把页码并进标题，所以拒绝）、标题超过 300 字、层次比前一行多出不止一级（或超过 32 级）、书签超过 20000 个。没有标题的书签导出时写成 `(untitled)`，导入时就是这个标题。文件里的书签超过 20000 个或嵌套超过 32 级时，`--export` 只写读到的前面那些，`--import` 和 `--auto` 把它们整份换掉，三个命令都在标准错误上给一句警告。文本文件最大 4 MB。`--import` 做出的书签都跳到那一页的顶上，原来的书签（包括链接类的）全换掉。文件作者没允许“拼装”和“修改内容”（权限位 11 和 4）、又没给所有者密码的加密文件，和有签名的文件，都拒绝。

## 5. 已知限制

1. **只有 Windows 版。** 阅读器和命令行工具都只能在 Windows 上运行。
2. **只认横排文字。** 文字识别只认横排。竖排的老书扫描件识别出来会是跨栏的横行，顺序会乱。
3. **没有框线的表格可能认不准。** 转 Excel 和 Word 时，没有框线的表靠文字对齐找出来。两列的“名称 | 说明”这类表、列间距很紧的表认不出来；有的图也可能被当成表。
4. **改字有限制。** 一次只改一行，跨行的段落不能一起改；有些重复使用的表单里的字也改不了。改完的旧字仍在文件的旧版本里，要彻底去掉，请用“另存为”。
5. **有签名的文件不能改内容。** 加水印、加页码、加图片、加文字、改字、旋转/删除/调顺序/插入页都会被拒绝。“签名图片”只是把图片放上去，不是数字签名；本程序不能签名，也不能验证签名。
6. **转成的 Word 和 Excel 不是原样复制。** Word 文件是可以编辑的版面，不会和原页一模一样；图表和绘制的图形不会转过去。
7. **加密只写 AES-256 和 AES-128。** 不写 RC4（太弱）；证书（公钥）加密不支持；打开的老文件里的 RC4 照样能读。AES-128 的文件密钥是按标准由密码、权限和文件编号算出来的，不是随机的（标准就这么定的），每个字符串和数据流的初始向量仍然是随机的。加密写的是新文件，不是在原文件后面追加。

8. **多个文件有限制。** 最多同时开 16 个；正忙的标签（保存、导出、压缩、识别、打印等）不能切走；一次开很多大文件、内存放不下时，没改过的标签会被放掉文件，再点它要重新读一遍（比切到刚用过的标签慢，一百页的文件约几十到一百多毫秒，大文件更久）；标签条上的路径提示只在鼠标放着时显示；已经有一个阅读器开着时从命令行再启动，文件交给那个窗口，所以新窗口不会出现（设置 `single_window=0` 可以关掉）。

9. **看的方式的限制。** 双页只有连续的一种（页一行接一行往下滚），没有“一次只显示一对页、翻页不滚动”的 TwoPageLeft、TwoPageRight 版式，文件里写了这两种就按“双页”和“双页（封面单独）”处理；从右往左的方向只在文件里写了才有，菜单里没有单独的开关。放映没有激光笔、黑屏、跳页和自动翻页；扫描页的大小各不相同时，每页按自己的大小放满屏幕，所以相邻两页的缩放会有一点点不一样。深色只是界面和页面周围，菜单和对话框仍是浅色。夜间模式下图片的颜色会反过来；4K 窗口里双页同时画两页，翻页比单页慢（最慢的“什么都没画好”的情形一行要 0.3 到 0.5 秒，平常看（后一行已经画好）几毫秒到几十毫秒）。

10. **涂黑有限制。** 只有一部分在框里的图形保持原样（被黑框盖住，没有被改）；Type 3 字形、软蒙版组里画的图不处理；字体文件不改；书签标题、命名目的地、附件、脚本、别的页的批注、没指向有标记的页的结构树元素、（没勾清除时的）文档信息和元数据不改，只报告（附件和脚本可以一起删）；批注的 `/RC` 是流时不读；颜色里选了图案、之后又选了别的颜色而没有 `Q` 时，那个图案当作还在用（不删）；表单字段自己的动作（脚本）不数也不删；同一个表单被两个名字画、而里面有要删的东西时，整个涂黑失败并说页码；字体不在页面资源里的文字读不出来，那一页整个失败；没有 `/Widths` 的标准字体（Helvetica 等）的字宽是猜的，所以标记碰到的那一行整行都删（提示一句），要在涂黑后检查那一页；字体的 `/ToUnicode` 表不剪（见上）；转了不是 90 度倍数的图片，框所在的那个外接框里的像素全涂掉（比框大，不会比框小）；一页最多 2 万个框；阅读器里的涂黑只做 40 MB 以内的文件（更大的用命令行）；做的时候不能取消。
